# Components

Public profile content lives in `src/config/site.ts`.

- `sections/`: hero, about, skills, timeline, projects, and contact.
- `layout/`: responsive navigation.
- `providers/`: theme and smooth scrolling.
- `chatbot/`: optional AI chat interface.
- `analytics/`: optional Firebase dashboards and tracking.

Keep presentation in components and identity, links, and sample content in the config.
